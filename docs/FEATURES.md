Subject: Operating Systems
Topic: CPU Scheduling
────────────────────────────────────
Q: What is the difference between preemptive and non-preemptive scheduling?

A: 
Preemptive Scheduling:
- Process can be interrupted and moved back to ready queue
- Higher priority processes get CPU immediately
- Requires timer interrupt
- Examples: Round Robin, SJF (preemptive), Priority (preemptive)
- Better response time
- Context switching overhead

Non-Preemptive Scheduling:
- Process runs until it terminates or blocks
- Simpler to implement
- No timer interrupt needed
- Examples: FCFS, SJF (non-preemptive)
- May cause starvation
- Lower overhead

Follow-up Q: Which scheduling algorithm can cause starvation?
A: SJF (Shortest Job First) — long processes may never get CPU if short processes keep arriving
```

Difficulty: Medium

Q: What is the difference between useEffect and useLayoutEffect?

A:
useEffect:
- Runs asynchronously after render
- Doesn't block browser paint
- Used for: data fetching, subscriptions, timers
- Browser may paint before effect runs

useLayoutEffect:
- Runs synchronously after DOM mutations
- Blocks browser paint until effect completes
- Used for: DOM measurements, synchronous re-renders
- Use sparingly (can hurt performance)

Example:
// useEffect — good for data fetching
useEffect(() => {
  fetchData();
}, []);

// useLayoutEffect — good for measuring DOM
useLayoutEffect(() => {
  const height = ref.current.offsetHeight;
  setHeight(height);
}, []);

Follow-up: When would you use useLayoutEffect over useEffect?
A: When you need to measure DOM and synchronously re-render before browser paints

Topic: Operating Systems
Section: CPU Scheduling Algorithms
────────────────────────────────────
Key Points:

1. First-Come, First-Served (FCFS)
   - Non-preemptive
   - Simple FIFO queue
   - Convoy effect: short jobs wait for long jobs
   - Avg waiting time: High

2. Shortest Job First (SJF)
   - Can be preemptive (SRTF) or non-preemptive
   - Optimal avg waiting time
   - Starvation: long jobs may never execute
   - Difficult to predict burst time

3. Round Robin (RR)
   - Preemptive with time quantum
   - Fair — every process gets CPU time
   - Small quantum: high context switching overhead
   - Large quantum: becomes FCFS
   - Time quantum: 10-100ms typical

4. Priority Scheduling
   - Each process assigned priority
   - Higher priority executes first
   - Starvation: low priority may never execute
   - Solution: Aging (increase priority over time)

Important Terms:
• Context Switching: Saving/restoring process state
• Throughput: Number of processes completed per time unit
• Turnaround Time: Total time from submission to completion
• Waiting Time: Time spent in ready queue
• Response Time: Time from submission to first response
```
